# diff 中新引用的符号必须在源码或依赖里有定义

新引用的函数、字段、配置、依赖，每一个都要能指出定义所在的 `file:line`，或者依赖清单里的对应条目。找不到，又不是这次 diff 自己新增的，就判为阻断。

## 为什么

AI 最常见的错误是调用不存在的 API、虚构字段、配错依赖。这类代码逻辑读起来通顺，人工评审时最容易放过去。

## 常见形态

- 调用了同名但不同签名的方法；
- 用了新版本才有的库 API，而 lockfile 里锁的是旧版本；
- 从 DTO 里读了一个实际上不存在的字段；
- 配置 key 拼错，或者用了另一个环境才有的 key。
